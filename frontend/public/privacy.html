# Privacy Policy **Last updated: June 2026** ## 1. Information We Collect BatchSwap is a non-custodial frontend. We collect minimal data: - **Public wallet address** — used only for fetching token balances and generating quotes - **Transaction hashes** — stored locally in your browser for transaction history - **Analytics data** — anonymous usage statistics via Vercel Analytics (no personally identifiable information) ## 2. What We DON'T Collect - Private keys or seed phrases - Personal identification (name, email, IP address) - Browsing history - Any data not explicitly listed above ## 3. How We Use Data - Wallet addresses: only to query blockchain state (balances, quotes) - Transaction history: stored only in your browser's localStorage - Analytics: aggregated, anonymous usage statistics ## 4. Data Storage - All user data is stored locally in your browser - We do not maintain any user database - No data is sold or shared with third parties ## 5. Cookies We use essential cookies only: - Language preference (English/Polish) - No tracking or advertising cookies ## 6. Third-Party Services - **1inch API**: wallet address sent to fetch quotes - **0x Protocol API**: wallet address sent to fetch quotes - **Routescan API**: wallet address proxied server-side to fetch token balances ## 7. Your Rights Under GDPR you have the right to: - Access your data (limited to browser localStorage) - Delete your data (clear browser storage) - Data portability - Object to processing ## 8. Contact privacy@batchbridge.xyz

# Instructions for Updating minikit.config.ts with Credentials

After generating `accountAssociation` credentials from the Base Build Account association tool, you need to update the `minikit.config.ts` file.

## Step 1: Open the configuration file

Open the file: `minikit.config.ts`

## Step 2: Find the accountAssociation section

Find the following code fragment:

```typescript
export const minikitConfig = {
  accountAssociation: {
    // This will be added in step 5 after generating credentials
    "header": "",
    "payload": "",
    "signature": ""
  },
  // ... rest of configuration
}
```

## Step 3: Enter the generated credentials

Replace the empty strings with values generated by the Base Build Account association tool:

```typescript
export const minikitConfig = {
  accountAssociation: {
    "header": "INSERT_GENERATED_HEADER_HERE",
    "payload": "INSERT_GENERATED_PAYLOAD_HERE", 
    "signature": "INSERT_GENERATED_SIGNATURE_HERE"
  },
  // ... rest of configuration remains unchanged
}
```

## Step 4: Also update .well-known/farcaster.json

After updating `minikit.config.ts`, you also need to update the manifest in `.well-known/farcaster.json`.

You can do this in two ways:

### Option A: Manual update

Open the `.well-known/farcaster.json` file and update the `accountAssociation` section:

```json
{
  "accountAssociation": {
    "header": "SAME_VALUE_AS_IN_minikit.config.ts",
    "payload": "SAME_VALUE_AS_IN_minikit.config.ts",
    "signature": "SAME_VALUE_AS_IN_minikit.config.ts"
  },
  "frame": {
    // ... rest remains unchanged
  }
}
```

### Option B: Use the manifest generation script

If you have installed dependencies, you can run:

```bash
npm install
npm run generate-manifest
```

The script will automatically generate the `.well-known/farcaster.json` file based on `minikit.config.ts`.

## Step 5: Check format correctness

Make sure that:
1. Values are exactly the same as generated (no extra spaces)
2. Quotes are properly closed
3. There are no TypeScript syntax errors

## Step 6: Local verification

Before deployment, you can check if the configuration is correct:

```bash
npx tsc --noEmit minikit.config.ts
```

If there are no errors, the configuration is correct.

## Note:

- **Do not share** your credentials publicly (do not commit to public repo without protection)
- After deployment, credentials will be publicly available in the manifest
- If you need to change the associated account, you must generate new credentials
